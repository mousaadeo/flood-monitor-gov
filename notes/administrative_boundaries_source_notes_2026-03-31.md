# ملاحظات مصدر الحدود الإدارية — 2026-03-31

تم التحقق من خدمة ArcGIS الخاصة بأبوظبي على الرابط:

https://arcgis.sdi.abudhabi.ae/agspublish/rest/services/OpenData/ADSDI_OpenData/MapServer/0?f=pjson

النتيجة الأساسية:

- اسم المجموعة: **Administrative Boundaries**.
- الوصف يذكر صراحةً أنها تحتوي معلومات عن **حدود الإمارات والبلديات والمناطق والمجتمعات**.
- الطبقات الفرعية الظاهرة حالياً:
  - `2` = Community
  - `4` = Districts
  - `818` = ADR Districts
  - `819` = ADR PostalCode
  - `6` = Municipality
  - `808` = Emirate
- صيغة الاستعلام المدعومة تتضمن **geoJSON**، ما يجعلها مرشحاً مناسباً لجلب حدود إدارية قابلة للرسم مباشرة داخل الخريطة.

الاستنتاج:

يوجد مصدر خارجي واعد يمكن الاعتماد عليه للحصول على **حدود إدارية حقيقية** بدل الاكتفاء بأشكال تقريبية. الخطوة التالية هي فحص الطبقات الفرعية `Districts` و`Community` لمعرفة عدد المعالم داخل نطاق أبوظبي، وأسماء الحقول، وإمكانية مطابقتها مع نموذج المناطق التسعين الحالي.
